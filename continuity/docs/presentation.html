The session ends.
The work should continue.

A session that ends, compacts, or runs out of context loses the thread. Leave the next session a way back.

record → handoff → pickup

Checkpoint while working. Wrap when finished.
Keep durable work in the record.

source: docs/glossary.md

01 · The durable boundary

The record holds the work.
The handoff points to it.

They have different jobs, so the next session does not have to reconstruct durable decisions from a transcript.

record

Your tickets, project status, documents, and their history. Your profile binds the workflow that reconciles them.

handoff

A thin pointer for one subject and one session: where to find the record, open loops, and the session’s uncommitted files.

The package provides the handoff engine. You choose the record.

source: docs/glossary.md; scripts/lib/handoff.py

02 · Checkpoint

Write the handoff now.

Checkpoint carries every session item the record does not yet hold, without finishing the work.

Context warning

At 50% or above, usable context data triggers a prompt to reconcile the record and checkpoint.

No persistence prerequisite

Checkpoint does not commit, merge, or push. It writes even if lint fails, and reports that failure.

source: skills/checkpoint/SKILL.md; scripts/lib/handoff.py: context_guard, checkpoint

03 · Wrap

Five steps, in a fixed order.

The checklist is the spine plus profile steps. It finishes by writing and validating the handoff.

1recordreconcile
2knowledgecapture
3lessonsfold in
4persistpersist
5handoffwrite + validate
Invalid handoff → wrap fails. A bound record must also be fresh.

The skill runs the plan. The checklist engine composes and checks it.

source: skills/checklist/SKILL.md; scripts/lib/checklist.py: compose, wrap_check

04 · Profiles and slots

Connect the spine to your workflow.

Four slots can be bound to commands. Profile steps add work around the spine; they cannot remove or skip it.

User profile

Applies to every session. Binds record, knowledge, lessons, and persist; lessons defaults to improve-harness.

Repository profile

Adds steps for its repository. Only own-worktree may follow the handoff, after a passing wrap check.

Unbound slots carry their items as open loops.

A grounded lesson can lead to a size finding; the user chooses one source for slim-harness. Edits stay uncommitted.

source: skills/checklist/SKILL.md; skills/improve-harness/SKILL.md; skills/slim-harness/SKILL.md

05 · Pickup

A new session, in either tool.

Claude Code and Codex discover the same handoffs. Worktree siblings share a repository root.

Candidates first

This subject, then siblings from other worktrees of the same repository, newest first within each group.

Revalidate before acting

Select a handoff and read its record. Without a current or sibling candidate, use local transcript fallback from either tool.

source: skills/pickup/scripts/pickup.py: handoff_candidates, run

06 · Hooks

Six hooks keep continuation visible.

Hooks supply context and checks around your work. They do not automatically run the wrap.

SessionStartCount handoffs at startup; restore after compaction.
PreCompactBack up raw hook input; remind before compaction.
UserPromptSubmitWarn when usable context usage reaches 50%.
PostToolUseTrack session touches in the ledger.
StopWrite a missing skeleton; flag own stale work.
PostToolUse · shellRemind once after commit, push, or passing tests.

Interactive sessions only. Codex adds a seventh handler: the actor guard before shell calls.

08 · Scope

Store continuation, not a second record.

The handoff stays thin so durable facts have one home.

In the handoff

Pointers, next action, open loops with producer identity, and the session’s uncommitted files. Pending artifacts come from the ledger.

Outside the handoff

Live ticket lists, project status, runtime posture, and material already in the record. The package provides no record store.

Raw pre-compaction input is a backup, not a complete transcript archive.

No cross-host synchronization or automatic session cycling is provided.

source: skills/checkpoint/SKILL.md; INTERFACE.md sections 1, 8; scripts/lib/handoff.py: pre_compact

09 · Install

Seven skills. Two tools.

Install from a checkout or a verified signed release. The guide owns prerequisites, configuration, verification, and removal.

Claude Code

claude plugin install continuity --marketplace "$PWD"
Run in the package root. Commands use /continuity:<skill>.

Codex

python3 scripts/install-codex.py
Run in the package root. The installer verifies seven trusted handlers.
