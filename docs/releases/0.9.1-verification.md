| Optional note absent or transcript explicitly partial | Preserve coverage gaps; may file after authorized routes complete. |
| Filing or link repair fails | Report capture pending rather than complete. |
| Local destinations differ from examples | Resolve local policy/profile body; ask only if unresolved or conflicting. |
